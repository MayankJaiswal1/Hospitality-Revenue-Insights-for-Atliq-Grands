# Hospitality-Revenue-Insights-for-Atliq-Grands

# 🏨 Atliq Grands Revenue Intelligence    
---

## 🚀 Project Summary  

An end-to-end hospitality analytics project designed to help **Atliq Grands**, a luxury hotel chain, reclaim lost market share using data-driven decision-making.  

This project follows an industry-standard analytics workflow — from requirement gathering to delivering actionable business insights via an interactive **Power BI dashboard**.

---

## 📌 Business Problem  

Atliq Grands is facing:

- 📉 Declining revenue  
- 🏨 Decreasing occupancy rates  
- ⚔️ Increased competition  
- 💰 Over-dependence on third-party booking platforms  

Management lacks a centralized analytical solution to identify:

- Underperforming cities and properties  
- Inefficient pricing strategies  
- Service-related revenue leakage  

### 🎯 Objective  

Build an interactive dashboard that allows stakeholders to **“peel the onion”** — starting from high-level KPIs and drilling down into cities, properties, and booking platforms to uncover root causes.

---

## 🛠️ Tools & Technologies  

- 📊 **Power BI Desktop** – Dashboard development  
- 🔄 **Power Query** – Data cleaning & transformation  
- 🧮 **DAX (26+ Measures)** – KPI calculations & trend analysis  
- ⭐ **Star Schema Modeling** – Optimized data relationships  

---

## 🗂️ Dataset Overview  

The dataset simulates real-world hospitality data and consists of:

### 📘 Dimension Tables
- Hotels  
- Rooms  
- Dates  

### 📙 Fact Tables
- Bookings  
- Daily Aggregated Capacity  

---

## 🔄 Data Preparation  

Using **Power Query**, the following transformations were performed:

- Promoted headers  
- Handled null values  
- Standardized data types  
- Customized weekend definition → **Friday & Saturday** (hotel industry standard)  

---

## 📐 Data Modeling  

A **Star Schema** was implemented:

- One-to-many relationships  
- Fact tables connected to dimension tables  
- Optimized for performance and scalability  

---

## 🧮 DAX Implementation  

Created **26+ measures** including:

- 💰 Revenue  
- 🏷️ ADR (Average Daily Rate)  
- 🛏️ RevPAR (Revenue Per Available Room)  
- 📊 Occupancy %  
- 🔄 Realization %  
- 📆 Week-on-Week (WoW) Change  
- 📈 Trend Indicators  

Custom calculated columns were also added for advanced date logic and categorization.

## 🔍 Key Business Insights  

### 💡 1. Dynamic Pricing Opportunity  

The analysis revealed a **flat pricing strategy**, where ADR remained constant despite occupancy fluctuations.

**Recommendation:**  
Implement dynamic pricing and weekend pricing strategies to maximize revenue.

---

### ⭐ 2. Service Quality Directly Impacts Revenue  

Example: Bangalore properties showed an average rating of **2.3**, leading to:

- High cancellations  
- Low occupancy  

**Insight:**  
Service quality strongly influences revenue performance.

---

### 🌐 3. Channel Optimization Gap  

- Heavy reliance on high-commission third-party platforms  
- No differential promotions on direct website bookings  

**Recommendation:**  
Introduce exclusive website discounts and loyalty incentives.
